Computer Fundamentals – Questions & Answers

1. What is a computer?
A computer is an electronic device that accepts data, processes it, stores it, and produces useful information.
2. What are the main components of a computer?
The main components include the Input Unit, CPU, Memory Unit, Storage Unit, and Output Unit.
3. What is CPU?
CPU stands for Central Processing Unit. It processes instructions and controls the operations of a computer.
4. What is RAM?
RAM stands for Random Access Memory. It temporarily stores data and programs that are currently being used.
5. What is ROM?
ROM stands for Read Only Memory. It is non-volatile memory that stores important instructions permanently.
6. What is computer software?
Software is a collection of programs and instructions that tells a computer what tasks to perform.
7. What is an operating system?
An operating system is system software that manages computer hardware, software, files, memory, and other resources.
8. What are input devices?
Input devices are hardware devices used to enter data and instructions into a computer. Examples include keyboard, mouse, scanner, and microphone.
9. What are output devices?
Output devices display or produce the results processed by a computer. Examples include monitor, printer, and speakers.
10. What is computer memory?
Computer memory is used to store data, instructions, and information needed by the computer during processing.
11. Who proposed the Stored Program Concept, and when?
Dr. John Von Neumann proposed it in 1945. It forms the basis of the Von Neumann Architecture used by most modern computers.
12. What are the three key concepts of Von Neumann Architecture?
(i) Data and instructions are stored in a single read-write memory. (ii) Memory contents are addressable by location. (iii) Execution happens sequentially, instruction by instruction, unless explicitly modified.
13. What technology defined the Second Generation of computers?
Transistors replaced vacuum tubes, along with magnetic core memory and magnetic disk storage. High-level languages like FORTRAN, COBOL, and ALGOL emerged, and the first operating systems were developed.
14. What technology defined the Third Generation of computers?
Integrated Circuits (ICs/chips) — making computers smaller, faster, more reliable, and cheaper, with CPUs capable of ~1 million instructions per second (MIPS).
15. What led to the Fourth Generation of computers?
The invention of the Microprocessor chip, using VLSI (Very Large Scale Integration) technology packing about 50,000 transistors on a single chip; semiconductor memory replaced magnetic core memory.
16. What are the three main functional units of a computer?
Input Unit, Processing Unit (CPU), and Output Unit — commonly described using the Input → Process → Output (IPO) model.
17. What are the two main components of the CPU?
The Arithmetic Logic Unit (ALU) and the Control Unit (CU). The CPU is called the "brain" of the computer.
18. What is the function of the ALU and CU?
ALU performs arithmetic operations (+, −, ×, ÷) and logical/comparison operations (>, <, ≥, ≤, =), while CU monitors and controls the entire processing sequence — directing input/output devices and coordinating how data flows through the CPU, without performing calculations itself.
19. Differentiate between Compiler and Interpreter?
A Compiler converts the entire High-Level Language (HLL) program into machine language at once and reports all errors together with line numbers. An Interpreter converts and executes the program line by line, stopping immediately when it hits an error.
20. What is an Operating System? Name any four functions?
An OS is a program that acts as an interface between the user and computer hardware. Key functions: Program Execution, Input-Output Operation Handling, File System Management, Error Handling, Resource Allocation, and Information/Resource Protection.
