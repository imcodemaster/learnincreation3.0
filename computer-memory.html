What is Computer Memory ?


So you learnt about Input and Output unit. Now it’s a time to learn about Memory unit. But before this let's recall various Hardware component of a computer system.

You have a Keyboard to give a instruction to computer, and to execute (process) the given instruction in order to gives you result (output) computer need to store information temporarily and that why it has a memory unit.


Or in other words you can say that -

Memory Unit is principle storage of computer, all the data or instruction that computer needs at that moment stored here for execution.

Hello Friends !!, Here you need to notice something about Memory Unit. Memory unit is act like a storage where data or instruction are stored so that they are available for the user if he/she is needed to run it repeatedly after several interval of time so he/she don't need to entering it each time through input devices. It’s store in a memory of computer.
Memory unit are divided into several types of storage (memory) depending upon a several factor, but here you need to know that mainly it’s of two types.
Volatile and Non-Volatile Memory. Don't worry you are going to learnt about these in this course.

A Computer can remember lots of thing because of memory unit. You can put a lot of number into a computer memory. You can also put number of names, jokes, program etc. into memory. Memory stores all your data and arranges it in alphabetical order by default.

Volatile Memory -


Volatile memory are named to that memory devices which needs power to maintain the stored information. Most of a volatile memory is made of a semiconductor like S-RAMs or D-RAMs (Random Access Memory).


Non-Volatile Memory -


Non-Volatile memory are named to that memory devices which don't needs power to maintain the stored information. Some Example of Non-volatile Memory are -


  • Flash Drive - commonly called Pen drive. (Secondary Storage devices.)

  • Hard Drive - Inbuilt in a CPU cabinet for storing data, like movies, song, games, etc. also a secondary stage devices.

  • Floppy Disk - Also known as Compact Disk or CD. Act like a secondary storage media with a lower capability of storage, up to 750 megabytes. DVD comes with up to 4 GB storage capacities. Now a day’s memory units are measured in Megabytes or in Gigabytes. Apart from these, others measurement unit are Terabytes, Petabytes etc.

Higher are memory in a computer gives you the Higher Performance. Memory is also divided into 2 sectors Primary or Temporarily Storage such as Random Access Memory (RAM) or a Secondary or Permanent Storage like Read Only Memory (ROM).


Some Memory unit is describing below -



Bit - It’s a logically 0 & 1 represent a passive or a active stage of component in an electric circuit.


Nibble - A word used to describe a group of 4 bit.


Byte - Group of 8 bit is known as Byte, which represents the data or character.


1 Byte = 8 bit
1 Kilobyte = 1024 bytes
1 Megabyte = 1024 Kilobytes
1 Gigabyte = 1024 Megabytes
1 Terabyte = 1024 Gigabytes
1 Petabyte = 1024 Terabytes
